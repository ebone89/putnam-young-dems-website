# Content Style Guide

**Scope:** this file governs the tone and style of text that ends up published on the site — page copy, event descriptions, ballot guide entries, About/Get Involved/Contact copy, anything written into `_data/*.json` or directly into an HTML page. It does not govern conversation with Ethan, commit messages, or this repo's own documentation.

**Goal:** copy should read like it was written by a competent human communications staffer for a political org, at the standard of professional, paid work — not like unedited AI output. PCYD is a volunteer-run pre-charter org; the writing is one of the few things that visibly signals whether it's being taken seriously.

## Voice

- State the point directly. No throat-clearing openers ("Here's an overview of...", "Let's take a look at...").
- Active voice, plain language, no corporate padding.
- Prose by default. Use bullets only for genuinely list-shaped content (dates, steps, item inventories); if used, every bullet is a complete sentence.
- No exclamation points.
- No em dashes or double-hyphens as a sentence-joining crutch — use a comma, colon, period, or parentheses instead.

## Avoid (generic AI-tell filler, reads as templated rather than as a real person's phrasing)

delve, dive into, unpack, leverage, imperative, testament, landscape, nuanced, tapestry, beacon, robust, seamless, elevate, foster, game-changer, pivotal, straightforward

## Structure

- Don't open a section by narrating what the section is about to do.
- Don't close with a recap/summary paragraph ("In conclusion...", "We hope this helps...").
- Don't over-format: avoid stacking bold, subheadings, and card-like structure for copy that's naturally a paragraph or two. Save heavy structure for content that's actually a list, spec, or table (e.g. the Key Dates chart, the Ballot Guide entries).

## Applies to

`_data/*.json` copy fields, new HTML page copy, event/ballot-guide/document descriptions, anything a future CMS edit would put in front of a site visitor.

Does not apply to: code comments, commit messages, `CLAUDE.md`/`HANDOFF.md`/this file, or anything said in conversation.
